# Grafana Dashboards

| Dashboard | Source / exporter |
| --- | --- |
| [`finomosec/raid-mdadm`](finomosec/raid-mdadm/) | finomosec — software-RAID (`mdadm`) host metrics |
| [`pihole/prometheus-pihole-exporter`](pihole/prometheus-pihole-exporter/) | [`reloaded/prometheus_pihole_exporter`](https://github.com/reloaded/prometheus_pihole_exporter) — Pi-hole v6 DNS + DHCP, multi-instance |
| [`rocm/device-metrics-exporter`](rocm/device-metrics-exporter/) | AMD ROCm `device-metrics-exporter` — GPU node + workload telemetry |
